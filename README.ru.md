# m3m-explain

Скилл для агентов, который объясняет что угодно: код от агента, концепцию, статью, идею. Он сам выбирает лучшую форму ответа: **текст → схема → анимированная страница → видео**. Чем сложнее тема, тем нагляднее ответ.

https://github.com/user-attachments/assets/e43edced-7121-4fc0-a83c-e1d91495a77f

*Демо на 13 секунд, со звуком.*

## Зачем

Идея [Андрея Карпаты](https://x.com/karpathy/status/2105819303471976479): модели пишут больше, чем мы успеваем прочитать, и наша работа смещается к тому, чтобы понимать их результат. Стена текста для этого — худшая форма. Для сложного материала каждая следующая ступень «ещё лучше»: схема лучше абзаца, интерактивная страница лучше схемы, а видео в стиле 3Blue1Brown лучше всего, когда суть в движении или превращении.

m3m-explain превращает это в лестницу, по которой агент идёт при каждом «объясни».

| Ступень | Когда | Что получите |
|---|---|---|
| 1. Текст | простой факт, определение, одна причина, команда | короткий ответ простым языком |
| 2. Схема | одна связь, которую проще увидеть: порядок, причина, зависимость | HTML-схема в одном файле |
| 3. Анимированная страница | шаги, пути, состояния, целая система | HTML-страница с плеером шагов и анимацией |
| 4. Видео | суть — движение или превращение | видео без голоса, со звуковыми эффектами (HyperFrames) |

<p align="center"><img src="media/poster-promo.jpg" width="560" alt="Четыре ступени: текст, схема, страница, видео"></p>

Скилл называет ступень, которую выбрал. Явный формат важнее («в 5 предложениях», «нарисуй», «сделай видео»). «Не понял» поднимает ровно на одну ступень. Видео сначала предлагается и без «да» не собирается, если только вы сами не попросили видео.

## Установка

### 1. Поставьте скилл

Одной командой (macOS или Linux):

```bash
curl -fsSL https://raw.githubusercontent.com/hydra8/m3m-explain/main/install.sh | bash
```

Или из клона:

```bash
git clone https://github.com/hydra8/m3m-explain.git
cd m3m-explain
./install.sh
```

### 2. Выберите, куда ставить

| Агент | Папка | Флаг |
|---|---|---|
| Claude Code | `~/.claude/skills/m3m-explain` | `--target claude` |
| Codex, Pi и другие агенты, которые читают `~/.agents/skills` | `~/.agents/skills/m3m-explain` | `--target agents` |
| Оба | обе папки | `--target all` |

Без `--target` установщик кладёт скилл во все из этих папок, которые уже есть. Если нет ни одной, создаёт `~/.claude/skills`. При установке через `curl` флаги идут после `bash -s --`:

```bash
curl -fsSL https://raw.githubusercontent.com/hydra8/m3m-explain/main/install.sh | bash -s -- --target all
```

### 3. По желанию: видео

Ступени 1–3 работают сразу. Для ступени 4 нужны скиллы [HyperFrames](https://github.com/heygen-com/hyperframes) от HeyGen (Apache-2.0):

```bash
./install.sh --with-video
# или: curl -fsSL https://raw.githubusercontent.com/hydra8/m3m-explain/main/install.sh | bash -s -- --with-video
```

Флаг запускает официальный установщик HyperFrames (`npx hyperframes skills update` и `npx hyperframes skills update faceless-explainer`). Для видео ещё нужны **Node.js 22+**, **ffmpeg / ffprobe** и **Chrome или Chromium**. Если чего-то нет, установщик только предупредит; системные пакеты он не ставит.

### 4. Проверьте

```bash
ls ~/.claude/skills/m3m-explain/SKILL.md   # или ~/.agents/skills/m3m-explain/SKILL.md
```

Откройте новую сессию агента и спросите: *«объясни, как работает хеш-таблица»*. В Claude Code можно вызвать `/m3m-explain`.

### 5. Обновление и удаление

- **Обновить:** запустите установщик ещё раз. Он заменит старую копию.
- **Удалить:** `./install.sh --uninstall` (или `curl … | bash -s -- --uninstall`). HyperFrames не трогается.
- **Посмотреть, что будет сделано:** добавьте `--dry-run`.
- **skills CLI:** скилл лежит в `skills/m3m-explain/`, поэтому `npx skills add hydra8/m3m-explain` тоже должен его найти (сами не проверяли).

## Как пользоваться

Просто спросите. Примеры и куда они обычно попадают:

| Запрос | Ступень |
|---|---|
| «Что такое идемпотентность?» | 1 — текст |
| «Нарисуй, как запрос идёт через nginx, бэкенд и базу» | 2 — схема |
| «Как компилятор превращает исходный код в машинный?» | 3 — страница и строка с предложением видео |
| «Объясни свой дифф» / «почему ты сделал X?» | главный случай — та же лестница |
| «Как волна бежит по струне?» | 4 — видео, после «да» |
| «Не понял» | на ступень выше |

Ответ приходит на языке запроса. По-русски скилл пишет по правилам простого русского и проверяет текст `scripts/ru_score.py`; по-английски — по правилам простого английского в духе ASD-STE100 и проверяет `scripts/ste_score.py`.

Просьба что-то исправить («почини», «почему падает тест» во время отладки) — не объяснение, и скилл не вмешивается.

## Куда сохраняются объяснения

Страницы и видео сохраняются в `explanations/<slug>/` в корне текущего git-проекта, а вне проекта — в `~/explanations/<slug>/`. В git ничего не добавляется; если не хотите их коммитить, добавьте `explanations/` в `.gitignore`.

## Требования

- `python3` — проверка страниц и оценка текста (только стандартная библиотека).
- Chrome или Chromium — скриншоты страниц (по желанию; без него скриншоты пропускаются).
- Видео — Node.js 22+, ffmpeg, ffprobe, Chrome, скиллы HyperFrames (см. шаг 3).

## Тесты

```bash
python3 -m unittest discover -s tests
```

51 тест: установщик в песочнице `HOME` (чистая установка, существующие папки, переустановка, путь с пробелом, пробный прогон, удаление, режим `curl | bash`), поиск скиллов, проверка страниц, расстановка звуков, оценка текста и проверка, что в репо нет личных данных.

Демо-видео собрано на HyperFrames — том же движке, что и ступень «видео».
